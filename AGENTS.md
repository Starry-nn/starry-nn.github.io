# Portfolio Verification

- Keep English and Chinese content synchronized and preserve existing static hosting.
- When adding or changing projects, inspect every project card, not just the first.
- The project grid must handle arbitrary item counts; never limit column rules to four explicit children.
- Verify all cards and detail dialogs in both languages at 320, 375, 390, 430, 768, 1024, and 1440 pixel widths.
- Check readable card widths, text wrapping, dialog headers, and horizontal overflow at both page and component level.
- Inspect desktop and mobile screenshots before publication. Do not hide layout defects with page-level overflow clipping.
- After publishing, verify the live page rather than relying only on local checks.
