开源热榜周刊 · Issue 001

统计周期：2026.07.20—2026.07.26

排名以 GitHub Weekly Trending 显示的本周新增 Stars 为主，并优先关注 AI、开发者工具、模型、Agent、数据基础设施与生产力工具。

1. bojieli/ai-agent-book

项目介绍：bojieli/ai-agent-book 《深入理解 AI Agent：设计原理与工程实践》的完整开源仓库，收录全书正文、PDF 与按章配套代码，从 Agent 循环、记忆、工具调用一路讲到工程落地。

为什么值得关注：本周新增 17,401 Stars，增速断层领先。它把分散的 Agent 工程知识整理成中文、可编译、可运行的系统教材，特别适合想从“会调用模型”走向“会搭 Agent 系统”的开发者。

华人参与者：李博杰 Bojie Li，作者 / Pine AI 首席科学家。项目作者与核心维护者，长期从事网络系统、云基础设施和 AI Agent 工程研究；公开 GitHub 资料显示其现任 Pine AI 首席科学家。 个人主页 ↗ GitHub ↗ X ↗ Email ↗

2. mattpocock/skills

项目介绍：mattpocock/skills 一套面向真实工程工作的 Agent Skills 集合，把资深开发者的操作方法沉淀成 Claude Code、Codex 等编码 Agent 可直接复用的任务说明。

为什么值得关注：本周新增 10,969 Stars，说明 Skills 正从提示词技巧变成新的工程资产形态。这个仓库的价值不只是模板数量，更在于展示如何把隐性经验包装成可执行流程。

3. koala73/worldmonitor

项目介绍：koala73/worldmonitor 一个实时全球态势感知仪表盘，用 AI 聚合新闻、地缘政治事件与基础设施状态，将分散信息统一到可浏览、可追踪的界面中。

为什么值得关注：本周新增 10,936 Stars。它把“AI 搜索”推进到持续运行的信息产品：不只回答问题，而是构建一张不断更新的世界状态图。

4. diegosouzapw/OmniRoute

项目介绍：diegosouzapw/OmniRoute 面向 AI 编码工具的开源模型网关，以统一接口接入数百个模型与供应商，并提供配额感知路由、自动降级和上下文压缩。

为什么值得关注：本周新增 9,965 Stars。模型供应愈发碎片化，OmniRoute 把价格、配额和可用性问题收进基础设施层，正中多模型开发团队的痛点。

5. stablyai/orca

项目介绍：stablyai/orca 一个管理并行编码 Agent 的开放式开发环境，可在桌面、移动端或 VPS 上调度不同的编码 Agent，并复用你已有的模型订阅。

为什么值得关注：本周新增 7,245 Stars。单 Agent 工作流正在走向 Agent fleet，Orca 把多任务并行、跨端查看和自带订阅组合成一个更接近生产力产品的入口。

6. tirth8205/code-review-graph

项目介绍：tirth8205/code-review-graph 本地优先的代码智能图谱，为 MCP 和命令行工具构建持久化代码库地图，让 AI 编码工具只读取与当前任务真正相关的上下文。

为什么值得关注：本周新增 6,565 Stars。随着代码库和上下文窗口同步膨胀，如何精准取上下文比一味塞更多 Token 更重要；它提供了可衡量的上下文压缩路径。

7. Nutlope/hallmark

项目介绍：Nutlope/hallmark 一套反“AI 味”设计 Skill，面向 Claude Code、Cursor 和 Codex，帮助生成的界面摆脱套路化渐变、空洞文案和千篇一律的组件排布。

为什么值得关注：本周新增 4,978 Stars。AI 已经能快速写前端，但视觉判断仍是短板；Hallmark 把审美约束变成 Agent 可执行的质量标准。

8. earendil-works/pi

项目介绍：earendil-works/pi 完整的 AI Agent 工具箱，覆盖统一 LLM API、Agent loop、终端 UI 与编码 Agent CLI，适合学习或二次搭建自己的 Agent 运行时。

为什么值得关注：本周新增 4,880 Stars。它把模型适配、循环控制与交互界面放在同一代码库中，是观察现代编码 Agent 内部结构的高密度样本。

9. jamiepine/voicebox

项目介绍：jamiepine/voicebox 开源 AI 语音工作室，提供声音克隆、听写与内容创作能力，把过去需要多套工具完成的语音工作流收进统一产品。

为什么值得关注：本周新增 4,493 Stars。语音生成正从 API Demo 进入创作者工具阶段，Voicebox 的开源桌面体验和完整工作流让它比单点模型更值得关注。

10. rohitg00/ai-engineering-from-scratch

项目介绍：rohitg00/ai-engineering-from-scratch 从零构建并上线 AI 系统的实践型学习仓库，强调亲手实现、理解关键组件，再将作品交付给真实用户。

为什么值得关注：本周新增 4,399 Stars。在框架快速更迭的阶段，从底层亲手实现仍是建立稳定能力的最佳方式；该仓库正好连接学习、构建和发布。
