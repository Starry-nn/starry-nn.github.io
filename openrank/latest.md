# 开源热榜周刊 · Issue 001

**统计周期：2026.07.20—2026.07.26**

> 排名以本周新增 Stars 为主，并优先关注 AI、开发者工具、模型、Agent、数据基础设施与生产力工具。

## 1. bojieli/ai-agent-book

**项目介绍：** [bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book) 《深入理解 AI Agent：设计原理与工程实践》开源全书，提出“Agent = LLM + Context + Tools”核心框架。10 章覆盖上下文工程、RAG、工具调用与 MCP、多智能体协作，配套 92 个实验和 7 种语言 PDF。

**为什么值得关注：** 本周新增 17,401 Stars，位居 GitHub 周增第一，是免费、系统、可运行的 Agent 工程学习路径。

**华人参与者：** [李博杰 Li Bojie](https://01.me/whoami/)，作者、Pine AI 首席科学家。中科大少年班本科，中科大与微软亚洲研究院联合培养博士；曾获微软学者奖学金，在 SOSP、SIGCOMM 发表论文，曾任华为“天才少年”。公开链接：[个人主页](https://01.me/whoami/)、[GitHub](https://github.com/bojieli)、[Email](mailto:bojieli@gmail.com)。

## 2. koala73/worldmonitor

**项目介绍：** [koala73/worldmonitor](https://github.com/koala73/worldmonitor) 实时全球情报仪表盘，整合 AI 新闻聚合、地缘政治监控和基础设施追踪；聚合 500+ 新闻源，双地图覆盖 56 种图层，支持 Ollama 本地 AI。

**为什么值得关注：** 本周新增 10,936 Stars，将零散的全球新闻和风险信号转化为持续更新的世界态势视图。

## 3. diegosouzapw/OmniRoute

**项目介绍：** [diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute) 开源免费 AI 网关，一个 endpoint 聚合 290+ 供应商和 500+ 模型，支持 33 种编码工具、19 种路由策略、12 层 Token 压缩和三级容错。

**为什么值得关注：** 本周新增 9,965 Stars，以 MIT 协议和零云依赖解决多模型成本、配额、稳定性与兼容问题。

## 4. tirth8205/code-review-graph

**项目介绍：** [tirth8205/code-review-graph](https://github.com/tirth8205/code-review-graph) 本地优先代码智能图谱，用 Tree-sitter 构建持久化代码映射，计算变更“爆炸半径”，支持 20+ 语言和 MCP。

**为什么值得关注：** 本周新增 6,565 Stars，让编码 Agent 精确读取受影响上下文并减少无效 Token。

## 5. Nutlope/hallmark

**项目介绍：** [Nutlope/hallmark](https://github.com/Nutlope/hallmark) 面向 Claude Code、Cursor 和 Codex 的反“AI 味”设计 Skill，包含 20 种主题、57 项检测和四种工作模式，由 Together AI 推出。

**为什么值得关注：** 本周新增 4,978 Stars，把设计判断转化为可复用的 Agent 规则。

## 6. Robbyant/lingbot-map

**项目介绍：** [Robbyant/lingbot-map](https://github.com/Robbyant/lingbot-map) 前馈式 3D 基础模型，仅用普通 RGB 摄像头即可流式实时重建；单 GPU 约 20 FPS，可稳定处理 10,000+ 帧。

**为什么值得关注：** 本周新增 3,640 Stars，降低具身智能获取实时空间世界模型的门槛。

**华人参与者：** Robbyant 研发团队，蚂蚁集团旗下具身智能公司。论文作者包括 Chen Lin-Zhuo、Gao Jian、Chen Yihang 等 11 人。公开链接：[技术主页](https://technology.robbyant.com/lingbot-map)、[论文](https://arxiv.org/abs/2604.14141)、[GitHub](https://github.com/Robbyant)。

## 7. 1jehuang/jcode

**项目介绍：** [1jehuang/jcode](https://github.com/1jehuang/jcode) Rust 编写的下一代编码智能体框架，约 14ms 启动，包含向量记忆、Swarm、多模型供应商、Firefox 自动化和自修改能力。

**为什么值得关注：** 本周新增 2,773 Stars，是兼顾性能、记忆和多 Agent 协作的轻量工程实现。

## 8. HKUDS/DeepTutor

**项目介绍：** [HKUDS/DeepTutor](https://github.com/HKUDS/DeepTutor) Agent-native 个性化学习平台，把辅导、解题、测验、研究和可视化统一进 Agent 循环，结合静态知识锚定和三层动态记忆。

**为什么值得关注：** 本周新增 2,380 Stars，展示了围绕长期学习者记忆构建连续教育体验的方式。

**华人参与者：** 赵冰禧 Bingxi Zhao，项目负责人、香港大学数据科学实验室成员；黄超 Chao Huang，指导教授、香港大学计算机系助理教授，研究图神经网络与推荐系统。公开链接：[项目主页](https://deeptutor.info/)、[实验室](https://sites.google.com/view/chaoh)、[Google Scholar](https://scholar.google.com/citations?user=-844YT0AAAAJ)。

## 9. MoonshotAI/kimi-code

**项目介绍：** [MoonshotAI/kimi-code](https://github.com/MoonshotAI/kimi-code) 月之暗面官方编码智能体 CLI，基于 Kimi K2.7 Code 和 256K 上下文，支持视频输入、MCP、Plugin、子 Agent 和 ACP。

**为什么值得关注：** 本周新增 1,589 Stars，是国产基础模型团队对标 Claude Code 的完整开源编码入口。

**华人参与者：** 杨植麟 Yang Zhilin，月之暗面创始人兼 CEO。清华计算机系本科、卡内基梅隆大学博士；曾任职 Google Brain 和 Meta AI Research，也是 XLNet 主要作者之一。公开链接：[人物资料](https://en.wikipedia.org/wiki/Yang_Zhilin)、[Moonshot AI](https://www.moonshot.ai/)、[GitHub](https://github.com/MoonshotAI)。

## 10. kvcache-ai/ktransformers

**项目介绍：** [kvcache-ai/ktransformers](https://github.com/kvcache-ai/ktransformers) 异构 LLM 推理与微调优化框架，采用存算分离和 CPU/GPU 协同推理，让消费级显卡运行大型 MoE 模型，相关论文发表于 SOSP 2025。

**为什么值得关注：** 本周新增 1,538 Stars，把昂贵的大模型推理进一步带向消费级硬件。

**华人参与者：** 清华大学 MadSys 团队，核心成员包括张博鑫、董建伟、陈宏涛等，首席顾问为中国工程院院士郑纬民。公开链接：[实验室主页](https://madsys.cs.tsinghua.edu.cn/)、[GitHub](https://github.com/kvcache-ai)。
