新手入门

把 README 理解成展示在 GitHub 个人主页上的一份介绍。

  1. 选模板：点击小卡片就能预览，「展开全部」查看更多排版。
  2. 改成你的：可调整资料、模块，也可在「自由编辑」中修改 Markdown / HTML。默认显示的是示例，不是你已登录的账号。
  3. 选一种完成方式：「交给 Agent」自动补全资料并发布；「自己复制 README」导出当前填写的内容，由你粘贴到同名仓库。

Agent 的目标：当前账号 / 同名仓库。网站不直接发布，不接收 GitHub Token。使用 Agent 需要本地安装或现有对话支持 GitHub 访问；首次登录和工具权限仍可能需要确认。

点击确认后，授权 Agent 创建或更新当前 GitHub 账号的同名公开仓库，仅修改 README.md。保留旧版并校验远端 SHA；不修改其他仓库。需要本地已安装 Agent，且 GitHub 已登录。

命令仅启动你的 Agent；网站不直接连接或控制本机程序。首次登录、工具权限或发布冲突仍可能需要你处理。

不需要安装 Agent，也不用向网站提供 GitHub 权限。

导出使用左侧当前填写的资料，不含 Agent 占位符。示例内容不会自动变成你的信息，请先检查名字、用户名和项目。

  1. 确认下面的源码，复制或下载 README.md。
  2. 在 GitHub 创建与你的用户名完全同名的公开仓库。
