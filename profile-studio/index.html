组件一键加入，更多灵感去原站看看。

内置排版由本站组合；组件保留原项目来源。外部图片由对应服务加载。

三步，更新你的主页。

  1. 选择排版；需要时进入「自由编辑」，导入或修改 README。
  2. 点击「交给 Agent」，选 Codex、Claude Code 或其他 Agent，审阅后确认并复制。
  3. 把命令粘贴到终端，或把指令发到已打开的 Agent 对话。Agent 会补全信息并发布到 当前账号 / 同名仓库。

需要对应 Agent 已安装、GitHub 已登录。网页只生成交接内容；未确认的草稿不会授权发布。GitHub 的最终字体、间距与图片缓存可能略有差别。

点击确认后，授权 Agent 创建或更新当前 GitHub 账号的同名公开仓库，仅修改 README.md。保留旧版并校验远端 SHA；不修改其他仓库。需要本地已安装 Agent，且 GitHub 已登录。

命令仅启动你的 Agent；网站不直接连接或控制本机程序。首次登录、工具权限或发布冲突仍可能需要你处理。
