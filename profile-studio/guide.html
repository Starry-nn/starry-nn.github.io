打开编辑器，边看边试 ↗
它做什么，不做什么？

这个工具生成的是 README.md：一份展示在 GitHub 个人主页上的介绍文档，不是独立的网站，也不是 GitHub Pages。网站无需登录，不接收你的 GitHub Token。

先选模板，再调整内容

  1. 点一张模板卡片。

    在编辑器顶部查看排版。「展开全部」可以看到更多风格，也可以搜索「作品」「终端」「动态」等关键词。

  2. 决定资料由谁填写。

    默认勾选「基础信息交给 Agent」：预览里的名字、项目都是示例，最终由 Agent 读取当前账号的公开资料。你手动修改过的字段会保留。

    如果准备自己复制 README，请先把用户名、名字、技能、个人网站和「项目」模块中的内容改成自己的。手动导出不会自动查询账号。

  3. 微调，再看效果。

    在「排版与组件」里切换页首、技能样式和项目布局，勾选或排序模块。可以用「深色预览」检查效果；想直接改源码，就进入「自由编辑」。

手机上先选模板，再点预览工具栏里的「编辑信息」即可跳到资料区。修改会保存在当前浏览器；换设备或清除浏览器数据不会同步，请及时下载备份。

方式一：交给 Agent

适合已经在使用 Codex、Claude Code 或其他具备 GitHub 访问能力的 Agent 的用户。请先确认 Agent 可以正常使用，并已获得你自己的 GitHub 授权。

  1. 点击编辑器右上角的「交给 Agent」。

    选择 Codex CLI、Claude Code，或「其他 Agent / 已打开的对话」。使用命令行时，再选择 macOS / Linux 或 Windows PowerShell。

  2. 检查范围，点击「确认并复制命令」。

    选择其他 Agent 时，按钮会变成「确认并复制指令」。确认前，预览和下载的草稿交接包都没有发布授权；「复制对话版指令」也只是生成草稿。

  3. 把命令或指令交给自己的 Agent。

    CLI 命令粘贴到电脑的终端运行，不是浏览器地址栏；对话版指令粘贴到已打开的 Agent 对话。网站本身不会启动你的本机程序。

  4. 让 Agent 完成并给出验证结果。

    它会读取当前账号的公开资料，保留你手动编辑的字段，备份旧 README，只创建或更新该账号同名公开仓库里的 README.md。完成后检查它返回的个人主页和提交链接。

这里的「自动」不等于跳过权限。

首次登录、工具权限、分支保护或远端冲突仍可能需要你处理。如果内容过长，不要硬塞进终端命令；选择对话方式，或把下载的草稿交接包交给 Agent，审阅草稿后再明确授权发布。

没有安装 CLI？可以直接使用已有且支持 GitHub 操作的 Agent 对话，或选择下面的手动方式。安装与登录请参考 Codex 官方文档 ↗、Claude Code 官方文档 ↗。

方式二：自己复制 README

只需要一个 GitHub 账号。不必安装 Agent，也不必向本网站授权。

  1. 先把示例改成自己的资料。

    特别检查用户名、名字、精选项目的仓库名称，以及网站链接。点击右上角「自己复制 README」，查看最终源码。

  2. 点击「确认并复制 README」，或下载文件。

    这里导出的是你当前填写的内容，不是让 Agent 补全的草稿。如果提示还有未填写的变量，先返回编辑器补全。

  3. 打开或创建同名公开仓库。

    例如，你的 GitHub 用户名是 octocat，目标仓库就是 octocat/octocat。不是 octocat.github.io。已有这个仓库就直接编辑，不需要再建一个。

  4. 保存为根目录的 README.md，并提交。

    创建仓库时可勾选添加 README；之后打开 README.md，点击编辑，把源码粘贴进去。检查 GitHub 预览后，点击「Commit changes」提交。建议先保留旧文件副本，再替换内容。

  5. 访问 github.com/你的用户名。

    确认个人主页出现新介绍。如果不显示，检查仓库是否公开、仓库名是否与用户名一致，以及 README 是否非空并放在根目录。

完整规则参见 GitHub Profile README 官方说明 ↗。

想更自由？直接编辑源码

  • 从模板继续改：先选一个模板，再点「自由编辑」。左侧修改 Markdown / HTML，右侧实时查看效果；手机上为上下排列。
  • 用自己的 README：点击「导入 .md」，选择小于 100 KB 的 UTF-8 文本文件。也可以直接把源码粘贴进编辑区。
  • 插入组件：用「＋标题」「＋表格」「＋组件」补充内容；开源资源会保留来源。导入他人内容前请确认可以复用。
  • 认识变量：{{DISPLAY_NAME}} 是名字，{{GITHUB_LOGIN}} 是用户名。交给 Agent 时会自动替换；手动导出时用当前填写的资料替换。自定义变量需要自己填好。
  • 注意模式区别：自由编辑以源码为准，模块开关和样式设置不会重写已有源码。点击模板会重新应用模板；每个模板的自由编辑草稿会在本机保留，重新进入「自由编辑」可继续。

预览不是完整的 GitHub Markdown 引擎。GitHub 不支持任意 CSS、脚本或嵌入页面；本站预览也会过滤不安全内容。最终效果请以 GitHub 为准。

第一次用，可能会遇到这些问题

为什么一打开是别人的名字和项目？＋

这是用于展示排版的示例，不代表网站已登录那个账号。选择 Agent 自动填写后，未手动修改的示例会由真实公开信息替换；手动发布则需要自己修改。

不想用终端，能完成吗？＋

可以。选择「自己复制 README」，按教程在 GitHub 页面粘贴提交即可。也可将已确认的指令发到支持 GitHub 操作的 Agent 对话。

图片没加载，或者 GitHub 上看起来不一样？＋

横幅、动态文字和技能图标依赖外部服务，可能暂时不可用；源码仍会保留图片链接。可以稍后重试，或换成纯文字模板。字体、间距和图片缓存由 GitHub 控制，不保证与本站完全一致。

复制按钮没有反应怎么办？＋

浏览器不允许访问剪贴板时，会显示源码框供你选中并复制；也可以直接下载 README.md。命令太长时请改用对话或草稿交接包，不要使用不完整的命令。

分享排版链接，会公开我的资料吗？＋

「分享这个排版」只分享基础模板与配色，不包含个人资料、自定义模块设置或自由编辑源码。需要完整备份时请下载文件，并自行判断其中哪些信息可以公开。

会覆盖我其他仓库，或者整站内容吗？＋

交接任务只授权修改当前 GitHub 账号同名仓库里的 README.md，不授权修改其他仓库。已有 README 会被新版替换，因此 Agent 被要求保留旧版并检查远端版本；遇到账号不符或冲突应停止。网站自身不执行发布。

直接从 GitHub 读取资料与选择项目

  1. 点击「从 GitHub 导入资料与项目」。

    输入用户名、GitHub 主页链接或仓库链接，点击「读取资料与作品」。这是公开查询，不是登录、授权或账号所有权验证。不需要 Token，不访问私有仓库。

  2. 搜索并勾选项目。

    公开仓库和 GitHub Pages 仓库子目录中的网站分别列出；网站从 index.html 路径识别，请核对在线地址。搜索当前已加载的项目；如果还有结果，可点击「加载更多仓库」读取下一页。所选项目追加到表单，带上名称、介绍和完整仓库链接，不覆盖已有项目。仓库语言只作为技术标签，不推断熟练度；不推断学历或任职。

  3. 核对后导入。

    可同时填入公开姓名、简介和网站，并保留手动编辑过的字段。公开接口可能被限流；可稍后再试，或手动填写项目完整链接。手填仓库名会根据用户名生成链接，完整 URL 则保留原地址；没有 URL 的项目只显示文字，不会伪造链接。

右上角 EN / 中文 切换界面、提示与 Agent 指令语言，不会自动翻译你的个人资料。

可扩展资料与公众使用说明

默认的 Alex Builder 是虚构示例，不是网站作者或访问者的账号。手动导出前必须换成自己的 GitHub 用户名。

按 GitHub 主页内容，按需添加

资料区的「项目」「开源贡献」「文章与资源」「自定义栏目」均可继续添加、上移、下移或删除，每类最多 30 项。删除后可用「撤销上次删除」恢复最近一项。只有必要的内容才需要填写，空栏目不会出现在模板预览中。开源贡献可填仓库、PR 或 Issue 链接；文章与资源可填博客、教程和工具。工作与教育经历不再提供表单，旧数据仅留在本机草稿中。技能标签可按 AI、前端、数据等方向搜索，点击选择或回车添加自定义标签，最多 15 个。

在「链接」里选择 LinkedIn、X、Google Scholar、Hugging Face、YouTube、个人网站或「其他」。常见平台可只填用户名，网站会生成完整链接；Google Scholar 和「其他」请粘贴完整链接。其他链接还可自己命名。GitHub 链接由当前用户名自动生成。

导入社区模板

点击「导入社区模板 / 我的模板」，可读取公开 GitHub README 文件链接，也可导入小于 100 KB 的 .md 文本文件或粘贴源码。确认拥有内容或已获得复用许可后，可保存到本机模板库（最多 10 个）。模板库支持使用、移出和撤销最近一次移出。模板切换前请下载备份重要修改。

默认先展示解析预览：可识别常见项目链接、开源贡献、文章与资源、技能、联系链接和其他栏目。工作与教育段落不填入新版表单，原文仍有备份。确认后追加到表单，使用当前模板重新排版；只有额外勾选时才采用原文姓名、用户名和简介。请核对所有事实和链接。复杂 HTML、SVG、图片和未知组件不能保证完整转换，原文仍保留在我的模板中及最近一次导入备份；取消自动解析可保留原排版并进入自由编辑。表单新增模块不会自动写入自由编辑源码。

内容、隐私与第三方服务

草稿、资料和导入模板保存在当前浏览器的本地存储中，不上传本站服务器，不跨设备同步；本站不接收 GitHub Token。共享电脑上请使用独立浏览器配置或隐私窗口，并及时下载备份。清除本站浏览器数据会删除本机草稿，操作前请先备份。

读取公开资料、仓库和 README 会连接 GitHub；横幅、图标和模板中的外部图片会连接对应服务，服务方可接收网络请求及图片 URL 中的展示文字。仅填写准备公开的信息，不要放入密码、Token、证件、住址或其他敏感资料。没有有效链接的项目可只显示文字；无效社交链接不会导出为可点击链接。

GitHub 上公开可见的 README 并不天然允许复用。请检查原作者许可，保留必要署名；图库目录的许可不代表每个被链接主页的许可。本站导入不会自动公开收录你的模板，也不会对其授权或内容真实性背书。发布后的 README 属于公开内容，发布前请自行检查。

选一种你喜欢的排版，开始吧。
