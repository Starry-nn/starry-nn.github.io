# SIGNAL 事件筛选机制（2026-08-15）

这套规则根据本周人工清单校准，目标是提高信息密度，同时保留“真正改变行业”的硬件、供应链和组织信号。

## 1. 先判断是不是事件

进入候选池的新增动作包括：

- 模型、API、开放权重、Agent 工作流、推理速度/成本和重要版本变化；
- 可复现的论文、代码、数据集、评测和临床/实验结果；
- 芯片、存储、数据中心、能源、云采购和算力融资；
- 融资、并购、IPO、独立运营、关键人才流动和组织重组；
- 安全报告、系统卡、内容溯源、监管、出口管制和重大事故；
- 具身智能、脑机接口、机器人部署、订单和量产；
- 指定 X 作者的原创技术、产品、组织、政策或市场动作。

普通消费电子评测、手机参数、开箱、促销、情绪争论、教程、回顾、泛泛播客更新和重复转载不进入首页。

## 2. 战略性例外

标题出现手机、电脑或相机，不会自动淘汰。只要正文同时出现模型/API、训练/推理、供应链/存储芯片、中国市场、数据中心/算力、融资/并购/IPO、组织重组或安全治理等信号，就保留为战略事件。例如 Apple–中国存储供应链属于保留项；荣耀手机发布属于过滤项。

## 3. 证据与呈现

- **A 级**：公司/实验室/监管/论文/代码一手材料，或 Bloomberg、Reuters、The Information 等高权威媒体的可核验报道。可进入高价值雷达，事实与推断分开写。
- **B 级**：36 氪、虎嗅、量子位、机器之心、硅星人等专业媒体，或 A 级媒体援引知情人士。可以进入雷达，但标题必须写“据报道/尚未敲定/待核实”。
- **C 级**：X、Reddit、播客或社区线索。只作发现；除非回到一手材料或第二权威来源，否则不进首页事实流。

高价值传闻不再一刀切删除，但必须显式标注不确定性，不能写成已发生的事实。

## 4. 去重与结构化

一件事只保留一条主卡，其他来源挂到“交叉来源”；同一模型的多个版本/标题按事件合并。每条卡必须有公司/组织、项目、事件类型、地区、日期、来源等级；无法归属的放在每个分类最后。所有分类按最新日期倒序，周一为周起点。

## 5. 本次校准新增的扫描方向

在原有 63 个公众号、Bloomberg、公司官网、论文、GitHub 和 X 名单之外，采集器现在显式提高以下关键词权重：AI 基础设施融资、存储/供应链、内部风险报告、开源安全治理、Agent 工作流、模型推理基础设施、数据中心招聘与组织变化。
